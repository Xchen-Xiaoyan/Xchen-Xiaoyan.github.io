信用卡客户违约风险预测Credit Card Customer Default Risk Prediction

课程团队项目(担任组长):构建违约预测模型,并把实验管理、数据漂移对比和容器化训练做成可复现的流程。 Course team project (team lead). Built a default-prediction model and made experiment tracking, drift comparison and containerized training reproducible.

PythonLightGBMFLAMLMLflowDockerKubernetes

我负责的部分What I did

  • 数据与特征:完成客户数据清洗和模型输入特征处理。Data & features: cleaned customer data and prepared model inputs.
  • 模型:使用 FLAML 自动进行算法选择与超参数优化,训练 LightGBM 违约预测模型,并在独立测试集上评估。Modeling: used FLAML for algorithm selection and hyperparameter tuning, and trained a LightGBM default model evaluated on a held-out test set.
  • 实验管理:用 MLflow 记录参数与指标,对比数据漂移前后的模型表现。Experiment tracking: logged parameters and metrics in MLflow and compared performance before and after data drift.
  • 工程化:通过 Docker 与 Kubernetes 运行容器化训练流程,保证实验可复现。Engineering: ran containerized training on Docker and Kubernetes so experiments are reproducible.
这是团队项目,目前暂无公开代码。 This was a team project; the code is not public at the moment.
